# apex_render
# ⚡ Apex Render

**Apex Render** is a system-level optimization module for the **Redmi Note 10 Pro (sweet)** on **HyperOS 4**.  
Locks the display to 60Hz and applies aggressive tweaks for **maximum battery** without losing fluidity.

> No config files. No WebUI. Just flash and forget.

---

## 📥 Install

1. Download the latest ZIP from [Releases](https://github.com/ibnz3a/apex_render/releases).
2. Flash via **KernelSU**.
3. Reboot.

---

## ✨ Features

- 🔒 60Hz hardware lock  
- ⚡ Schedutil tuned (up=0, down=30)  
- 🎮 Adreno 618 optimized  
- 🧠 VM tuned (battery/fluidity balance)  
- 🌐 Network optimized (BBR + FQ + ECN)  
- 🗑️ Extended debloat (Sebastián MTZ list)  
- 🧹 Google tamer (analytics, hotword, etc.)  
- 🔋 Aggressive Doze & wakelock blocking  
- 🛡️ Kernel hardening (ptrace, ASLR)
